New opt-in setting: approve volume releases automatically. A digital release under a size limit (12 GB by default) is grabbed without asking when the only reasons it waited were that it names no volumes, adds chapters, or is over the auto-grab size. A release Maki is unsure about, including one whose language is in doubt, still waits for you. An approved release only replaces files it is at least as good as; a protected file or a better copy keeps its chapters.
