section: Library
---
Auto-tag rules tag a series as it is added when it matches every condition you set: genre, type, content rating, root folder, who added it, and how (search, Discover, a request, an import list, a Mihon import or a library import). Rules only act on new series. To tag what is already in the library, use Apply to existing series on a rule, which shows how many series it will tag first. Find them under Settings, Library, Auto-tag rules.
