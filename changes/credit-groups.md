type: feature
section: Library
---
Settings > Library > Credit pages has a list of the release groups behind the credit pages and ads Maki found, each with its pages and the series and chapters that carry them. Maki suggests each group's name from the text on its pages and, where your files already name a group, takes the name most of them agree on. You confirm or correct a name, mark an aggregator site's ad so it never names a group, and say for any page whether it should always be hidden or always shown, which applies to every chapter that carries it. Then one button gives that group to every chapter whose file has none and renames the files your naming format would name after the group. A group a file already has is never replaced.
