section: Interface
---
Dialogs, drawers and section titles now share one build across the app. Every dialog has the same heading and the same pinned footer with Cancel on the left of the main action, and confirmations all use the same dialog. The Chapters, Files and Scrobbling tabs on the series page, the Stats panels and the Upcoming groups use the same section header as the rest of Maki, and empty lists use the same empty state.
