type: improvement
section: Discover
---
The filters on Discover, Add series and creator pages are now one row of buttons above the results instead of a tall panel. Each button shows what it is set to and opens its options in a small popover, set filters move to the front, and filters that don't fit the row wait behind "Add filter". Recommended now applies changes as you make them, so it no longer has an Apply button. Save as default and Hidden everywhere are in the "..." menu at the end of the row.
