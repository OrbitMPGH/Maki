---
type: feature
section: Library
---
Drop folder: point Maki at a folder in Settings > Library and it checks it every few minutes. A comic or folder whose ComicInfo link or name matches exactly one series in your library is imported into that series once its size has stopped changing, copied or moved as you choose. Nothing already in the library is replaced. Anything that matches no series, or more than one, stays where it is and is listed on the Manual import tab for you to place by hand. Imports from the drop folder show up in the Activity history.
