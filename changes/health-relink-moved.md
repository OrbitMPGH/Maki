---
type: feature
section: Health
---
Health finds where a missing archive moved, by name, size and page hashes, and relinks it by itself after each library scan, for example when a series folder was renamed outside Maki. Matches on name alone wait on the Missing filter for you to confirm. The Unlinked filter is split by reason, damaged files get "Get a new copy", and size mismatches get "Update the record". Bulk actions report what failed.
