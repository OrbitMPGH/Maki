type: feature
section: Health
---
The Health page shows what Maki is busy with right now, next to its current processor and memory use: scheduled jobs mid-run, server Enhance for readers, Prepare ahead, page conversion, downloads, bulk series edits and source matching. A job or bulk edit can be stopped from there, and the conversion pass and the download queue paused. Below the checks, a list of scheduled jobs shows when each last ran and runs next, with Run now to start one straight away.
