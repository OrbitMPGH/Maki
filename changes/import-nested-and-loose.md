type: improvement
section: Library
---
The library import now looks inside grouping folders such as `A-Z/` or a publisher folder, up to two levels deep, and offers the series folders it finds there. Importing one moves it up to the root folder. Comics sitting loose in the root folder are grouped by series and offered as their own rows; they are moved into a new folder only when you import them, and undoing the import puts them back.
