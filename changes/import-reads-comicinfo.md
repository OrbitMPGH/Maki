section: Library
---
The library import scan now reads the ComicInfo.xml in each folder's first CBZ, and a Mylar `series.json` beside the files. A MangaBaka, AniList, MyAnimeList or MangaUpdates link in ComicInfo matches the folder to that exact series, and a series name in either file is searched before the folder name. Each row says which of these found its match.
