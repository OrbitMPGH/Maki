section: Library
---
Select mode in the Library has more bulk actions, each with the same progress and Stop button as the others:

- Rescan files and Rename files. Rename asks first and skips any series with a download in progress or a name collision.
- Mark read or unread. Read marks every chapter with a file without logging it as reading, so Rewind and your reading days stay as they are.
- Incognito, Clean up read files and Page conversion, set for the whole selection at once.
