---
type: feature
section: Library
---
The Library can group what it shows by status, tag, type or root folder (root folder only when you have more than one). Each group gets a header with its colour, name and count, and clicking it folds the group away. The sort applies inside each group, a series with several tags is listed under each of them, and series without a tag go in a "No tag" group at the end. Grouping works in the grid, list and table, is part of the link, and is saved with a saved filter. Folded groups are remembered in this browser.
