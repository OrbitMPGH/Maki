---
type: feature
section: Downloads
---
Downloads pause by themselves when a library folder's drive runs low on space. Each root folder keeps 5 GB free by default, which you can change (or set to 0 to turn it off) in Settings, Library. Downloads and torrent grabs for series in that folder wait, other folders keep downloading, and everything carries on once there is room again. Activity says which folder is held and how much space it has.
