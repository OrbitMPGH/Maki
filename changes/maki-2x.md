**Maki 2x**, Maki's own server upscaling model. It aims for the look of Real-ESRGAN at about a third of the cost, so pages upscale much faster. It's the new default server method and is marked Recommended in Settings > Library > Server upscaling. It comes with Maki, so there is nothing to download, but server upscaling still stays off until an admin turns it on.
