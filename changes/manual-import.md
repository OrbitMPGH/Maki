section: Library
---
Manual import: a new tab on the Import page lets you browse to a folder or file on the server, see the chapter and volume each file carries, pick the series it belongs to and import it. The review shows which chapters each file brings and which existing files it would replace, and you can copy (or hardlink) the files or move them. Admins can browse anywhere on the server; other users with the import permission only inside their own root folders. Manual imports show up in the Activity history.
