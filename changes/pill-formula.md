Label pills look the same everywhere: a tint and an edge in the pill's own colour, the style the series header already used.

- In the chapter table, the source pill has one look whether the file was downloaded, imported or came from a torrent. Volume, quality and file state pills have an edge, and Read is a tinted pill like its neighbours.
- In the Library list and table, status, download state and Read are tinted pills, no longer solid fills.
- The same goes for "wanted" in the Progress card, Health history, the shortlist and the source tags in Manage sources.
