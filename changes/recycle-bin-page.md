The recycle bin has its own page instead of one long list in Settings. Files are grouped by series with the newest deletions first, large groups start folded, and you can filter by series, file name or why the file was removed. A series that was removed whole can be restored or deleted in one go. Settings keeps the retention days and a link to the page, and the command palette finds it by name.
