section: Library
---
Root folder rules send a new series to the right root folder by its type, genre, content rating, who added it or how it came in, for example every manhwa and manhua to a webtoon folder. Rules are tried in order and the first match wins; with no match a series goes to the first root folder as before. The add form and the request approval dialog open on the folder a rule picked, and you can still change it. Import lists without a chosen folder and Mihon imports use the rules too. Library imports and series already in the library are never moved. Find them under Settings, Library, Root folder rules.
