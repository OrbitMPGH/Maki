type: feature
section: Sources
---
You can now choose which scanlation group's upload Maki takes when MangaDex has several copies of a chapter. Set preferred groups (in order) and blocked groups for every series from the MangaDex row in Manage sources, and override them for one series from its actions menu, which suggests the groups that actually upload that series. A chapter released only by blocked groups is taken from another source instead.
