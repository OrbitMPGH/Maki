The tallest Settings cards are shorter. Notifications, server upscaling models, backups, file name parsing languages and unmatched import list entries open in a window from their card, and the card shows what is set. Volume releases, the upgrade scan, the download client's torrent handling, server upscaling and folder naming on import show each setting's value on a row that opens its fields. Languages lists only the ones you use, with the rest as buttons to add.
