type: feature
section: Sources
---
Sources can go through a proxy. Under Settings > Downloads > Source proxy, set one HTTP proxy and pick the sources that use it, for sites that block your VPN or server's address. The headless browser, FlareSolverr's solves, chapter lists, page images and covers for those sources all go through it, and Maki never falls back to a direct connection when the proxy is down.
