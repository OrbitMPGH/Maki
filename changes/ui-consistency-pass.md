A consistency pass across the app:

- Filters work the same way everywhere. The Discover "Show more" modal and the custom rail editor use the same live filter bar as Discover, and Health, Import, Manage sources, Import lists and Manage signals use the same chips and filter buttons. Sort is one button with a direction arrow on every list that has it. The Library shows each active filter as a chip you can remove, with a Clear action.
- "Show more" on a recommendation rail shows the same cards as the rail, with the reason under each poster, and can switch to a list. Every "Show more" modal keeps its density in the "..." menu, like the Add page.
- The hints on the series page (mark complete, archive, rate) share one look, and the "Continue from the anime" note is a regular callout with a real button. Source links show their status with dots, and Download order is picked from a list instead of a dropdown.
- Download queue, Read cleanup and Library health settings open their numbers as rows you drill into, and Smart download now sits inside Download queue. Cards that open a list in a modal show a one-line summary with a Manage button. Connection cards say Not set up, Not tested, Connected or Failing in their header. API keys, URLs and paths can be copied with one click.
- Dialogs share their title and button layout, and Rebuild all in the image cache asks before it runs.
- The reader's end screen takes a flat wash of the cover's colour instead of a blurred copy of the cover.
