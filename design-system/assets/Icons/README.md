# Icons

A representative set of the Tabler Icons (outline) Maki uses most: trash, plus, alert-triangle, eye, eye-off, refresh, check, download, sparkles, clock, chevron-right, flame, book, search, player-play, star, file-zip, settings, layout-dashboard, library, compass, home, inbox. The app draws them from `@tabler/icons-react`; the full set is at tabler.io/icons.

The files are the raw Tabler SVGs, drawn in `currentColor` with a 2px stroke on a 24px grid, so shown as images they render black. In the app they inherit the surrounding text colour: `brand-fg` in section headers, the tone colour in stat tiles, white in cover badges. Render them at 20px with stroke 1.8 to 1.9 in headers and tiles, 16px in buttons, 11 to 12px in cover badges.
