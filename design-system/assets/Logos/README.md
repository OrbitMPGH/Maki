# Logos

`maki-mark.svg` is the brand mark: a maki roll with a face, drawn in fixed inks (`mark-cream` body, `mark-nori` bands, `mark-ink` outline and features, `mark-blush` cheeks). It is also the favicon. `maki-mark.png` is the 194px raster of the same mark for places that need a bitmap.

Show it at 30 to 42px inside the 44px `brand-mark` tile, beside the "Maki" wordmark set in the `wordmark` style. Never recolour it, never put it on a brand fill, and never set it smaller than 16px. There is no separate wordmark file: the wordmark is live text in Bricolage Grotesque.
