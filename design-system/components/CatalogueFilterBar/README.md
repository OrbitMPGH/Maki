# CatalogueFilterBar

Discover's catalogue filters appear in one row of small buttons. Set filters lead with a tint and a border in the accent, and show their current value. Unset filters that run out of room move into Add filter, which opens a drill panel. An open editor keeps the buttons in place until it closes.

Each button opens a popover for its filter. The controls at the end can show the live result count, saved filters, Reset and a menu for defaults and hidden content. Use the same button treatment for sort and filter menus in list toolbars. Library filters use `TagChip` for the selections shown below the toolbar.
