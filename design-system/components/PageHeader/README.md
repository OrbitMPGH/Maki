# PageHeader

The title row at the top of a route: title and optional description on the left, actions on the right, wrapping on narrow screens.

The title uses `type-page-title` and centres in a 44px row, so it stays on the same baseline as the actions across routes. An optional description sits directly below in `ink-3`, capped at 620px. `compact` shrinks only the description to `type-meta`.

Pass `title`, optional `actions` and `compact`. Add a description when it supplies a consequence, requirement or explanation the title cannot supply.

**Don't:** hang any other panel, hero band or stats beside the header. The cinematic band belongs to the series page, the Discover modal, sign-in and Rewind only.
