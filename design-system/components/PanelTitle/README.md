# PanelTitle

The title inside a panel or card, one tier under a SectionHeader: display face, 16px, 700, in `ink-hi`, with an optional 16px icon in `brand-fg`. Every panel title on a page shares it, so two panels side by side never disagree (Synopsis next to Sources, the Stats panels, the Taste cards, the Account groups).

**The consumer provides:** `children` (the title), an optional `icon`, and `order` (2, 3 or 4) for the heading level, 3 by default. A label that sits over a panel from outside stays a SectionHeader.
