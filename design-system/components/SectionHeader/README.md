# SectionHeader

The heading above a rail or grid: an accent icon, the title, an optional count, and a rule running to an optional right-aligned action.

The icon is a Tabler icon at 20px, stroke 1.9, in `brand-fg`. The title uses `section-title` (display face, 1.3rem, 700). The count is a `radius-control` pill in brand at 14% with `brand-fg` text, tabular figures. The rule fades from brand at 32% into `hairline`, giving a run of rails a line to read down.

**The consumer provides:** `icon`, `title`, optional `count` (omit it when the rail already shows how many it holds, as Home does), optional `action` (a `subtle` Button: "Find more", "Refresh").

Shared by Discover, the series page's related rail and Home.
