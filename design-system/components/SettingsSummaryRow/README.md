# SettingsSummaryRow

A settings panel can summarize what's configured and open a modal to edit it. The row shows its label over a summary in `ink-3`. A small default button names the action, such as “Choose languages”. On narrow panels it wraps under the summary. Adjacent rows share a `hairline`.

Use `SettingsDrill` when the editor fits inside the panel. It wraps `DrillPanes`, giving the current value more room than a popover and aligning the row icons with neighbouring controls.
