title: Maki's reader and shortcuts
description: Reading modes, reading profiles and the keyboard shortcuts in Maki's built-in reader.
---

This page covers how to set up and drive the built-in reader day to day. For what the reader can do
overall, see the [reader feature overview](/Maki/features/reader/).

## Reading modes

The toolbar's layout setting picks one of three modes:

- **Single page** shows one page at a time. Keys: `1`.
- **Double page** shows two pages side by side. Keys: `2`.
- **Continuous** scrolls the chapter as one strip, which suits webtoons. Keys: `3`.

Other settings you will reach for often:

- **Direction** is right to left for manga or left to right. Press `D` to switch.
- **Page fit** is **Fit height**, **Fit width**, **Fit screen** or **Original size (1:1)**.
- **Crop borders** trims plain white or black margins. Press `C` to toggle it.
- **Wide pages** (single page layout only) can be shown whole, split into two pages, or rotated to fit.
- **Tap zones** (paged layouts only) turn the page when you click the edges of the screen.

## Reading profiles

A reading profile is a saved set of these settings. Create and edit profiles under **Settings →
Reading → Reader profiles**. Each profile has a name and can apply automatically to one or more
series types. Series types that no profile covers use **Default**, which you can edit too.

Maki picks the settings for a series in this order. The first one that is set wins:

1. The override you saved for that series.
2. The profile you pinned to the series.
3. The profile for the series' type.
4. Your reader defaults.

In the reader, the **Reading profile** control in the settings popover shows which one is in use. It
offers **Auto** (labelled with the profile it picked, or **my defaults**), each of your profiles, and
**Just this series**. The line under the control says what your next change will touch: this series
only, the profile in use, or your reader defaults.

The popover also has **Keep the screen awake** and **Incognito (don't record this session)**.

## Keyboard shortcuts

Press `?` in the reader to open the list. Keys are ignored while focus is in a text field, and
combinations with Ctrl, Cmd or Alt are left to the browser.

| Key | Action |
| --- | --- |
| `→` or `Space` | Next page. Reversed when reading right to left. |
| `←` or `Shift` + `Space` | Previous page. Reversed when reading right to left. |
| `Home` / `End` | First page / last page |
| `1`, `2`, `3` | Single page, double page, continuous |
| `D` | Switch reading direction |
| `C` | Crop borders on or off |
| `+` (or `=`) / `-` | Zoom in / zoom out |
| `0` | Reset zoom |
| `F` | Full screen |
| `T` | Page thumbnails |
| `B` | Bookmark this page |
| `H` (hold) | Show the original page while the key is held, if enhancement is on |
| `Esc` | Back to the series page. Outside full screen only, since `Esc` leaves full screen first. |
| `?` | Show or hide the shortcut list |

In continuous mode, `Space` scrolls the strip as a normal page would, except on the last screen,
where it moves on.

:::tip
A button that has keyboard focus takes `Space` for itself. Click the page or move focus back to the
reader before using `Space` to turn pages.
:::
