## Cross-cutting rules

- **Adding a source**: add one `ISource` impl in `Maki.Sources` + one `AddSingleton<ISource, ...>()` registration. Return chapters via `SourceChapterList.Normalize` (dedupes by `(Number, Volume, Language)`). Tag each chapter with the language **the site says it is**, never hardcoded `"en"` (`Normalize` canonicalizes via `SourceLanguages.Canonical`, and `Chapter.Language` drives chapter identity, CBZ `LanguageISO`, and the ` [es]` filename suffix). Set `Kind`/`Content`/`Rating` whenever they differ from the defaults (`Aggregator`/`Manga`/`General`), as `/search/sources` surfaces them as UI tags. Update the table in `docs/sources.md`, the copy inside the "Show all sources" dropdown in `README.md`, and the "N sources are built in" count there.
- **Multi-language and `SupportsLanguageFilter`**: `SupportsLanguageFilter` means `ListChaptersAsync` honours `languageFilter` (comma-separated, parse with `SourceLanguages.Parse`, where null means `en`, not "all"). Only **MangaDex** (`translatedLanguage[]`) and **MangaFire** (Lang dropdown / `AllLanguages`) declare it. **MANGA Plus** and **Webtoons** are multi-language but correctly declare `false` because each locale has its own series id/service (a second language is a second mapping; Webtoons folds non-English locales into a 4-segment `SourceSeriesId` `{locale}/{genre}/{slug}/{titleNo}`, searches all 7 locales concurrently with English first, and only rethrows if every locale fails).
- **`SourceCapabilities.FreeWindowListing`**: declare this on any source whose chapter listing only shows what is currently free (ComicWalker, every GigaViewer site). Without it, chapters whose free window closes get flagged `Chapter.DelistedAt` with weekly inbox rows. Sources that list everything and fail locked chapters at page time (MANGA Plus, Webtoons, Naver Webtoon) do not declare it. Suwayomi and custom sources cannot declare it (`SuwayomiSource` returns `None`, `CustomSource` maps only FlareSolverr).
- **Images**: always go through `Maki.Core.Images` (`ImageCodec`, `Raster`), never `NetVips.Image` directly. `ImageCodec`'s static constructor locks down libvips loaders and disables the operation cache; bypassing it can run before that initialization. Descramblers decode with `Raster.Decode` and encode with `Raster.Encode*` (JPEG 4:2:0). BMP has no loader (header-only sizing). Do not reintroduce ImageSharp (4.x needs a Six Labors license key in Release).
- **Page fetching**: `GetPagesAsync` returns `PageRequest`s carrying their own `Headers` (or `Fetch` hatch / `XorKeyHex`) end-to-end. Always resolve pages at **download** time, never enqueue time (MangaDex at-home URLs are short-lived).
- **Cross-site tracker ids (`ISource.GetExternalIdsAsync`)**: consumed by `SourceMatchService`. Four sources publish them: **MangaDex** (in search `attributes.links`, populates `SourceSeriesResult.ExternalIds`), **Atsumaru** (`manga/page` has `mangaBakaId`/`malId`/`anilistId`/`kitsuId`/`mangaUpdatesId`; search index has `weebCentralId`, merged via `SourceExternalIds.Merge`), **WeebCentral** (AniList + MangaUpdates anchors on series page), and **MangaFire** (MAL + AniList + MangaUpdates + MangaDex via DOM `a.tracker-link` in `.title-detail__trackers`, not detail JSON).
